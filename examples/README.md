# 已有验收资料与Skill

这里复用现有CampusClaw验收环境的文本内容，不另编资料，不包含账号密码、会话、工具连接令牌、数据库备份或向量索引。

- `knowledge/`：13份已有知识库正文，包括方程/函数知识、青竹与星桥演示规则，以及“星桥班课程考核与提交说明”。演示规则是虚构验收语料，不代表本课程正式要求。
- `skills/解题引导.md`：内置技能的现行文本，空库已经预置，无需重复上传。
- `skills/人工测试解题引导.md`：已有上传技能，匹配“青竹验收”，回答应按规程包含技能命中标识并给出下一步提示。
- `skills/MCP验收解题引导.md`：已有两工具串联规程。先登记并连接`campus-tools`，再上传；工具声明及应用授权均需配置。

知识库正文保留原内容；Skill按当前有效的名称、条件、启用、资料/工具声明和规程导出为课程文本格式。修改过的历史原始上传头字段不作为生效配置。

这些文件随仓库提交，但不会自动覆盖数据库或上传目录。首次启动已有4账号、两班基础资料、每班2应用/2模板/1内置Skill；额外资料可通过`python apitest/run_all.py --init-demo`一键导入并绑定，无需在界面逐份上传。完整操作见[教师首次测试指南](../docs/teacher-quickstart.md)。
