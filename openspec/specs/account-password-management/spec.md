# account-password-management Specification

## Purpose
提供本地课堂演示的学生注册和账号密码生命周期管理，在简化初始口令使用的同时强制首次改密、撤销旧会话并保持现有角色、班级与教学数据安全。

## Requirements

### Requirement: 演示功能环境边界
系统 MUST 仅在显式本地演示模式允许默认口令注册和批量重置，生产不得启用；矛盾配置 MUST 启动失败。
#### Scenario: 生产禁用
- **WHEN** 使用生产配置请求注册或执行重置
- **THEN** 请求被拒绝且数据库不变；生产加演示开关的配置启动失败

### Requirement: 显式四账号重置
系统 MUST 提供显式操作仅重置 teacher_a、teacher_b、student_a1、student_b1 为 bcrypt 初始口令 123456，标记首次改密并撤销全部旧会话；普通启动不得重置。角色、班级、材料和知识库 MUST 保留。
#### Scenario: 四账号重置与数据保留
- **WHEN** 在本机显式重置四账号
- **THEN** 四账号均能以 123456 登录但须改密，旧密码和旧 Session 失效，原有业务行与文件不变
#### Scenario: 启动不重置
- **WHEN** 用户改密后再次启动或初始化
- **THEN** 其新哈希与已注册用户保留，不恢复初始口令

### Requirement: 学生公开注册
系统 MUST 在演示登录页提供注册入口，注册仅接受用户名和 A/B 班级，后端固定 student、哈希初始口令并强制首次改密。重复用户名、非法班级和权限字段 MUST 被拒绝。成功页 MUST 提示初始口令，API 不含口令或哈希。
#### Scenario: 注册学生
- **WHEN** 提交唯一用户名与 A 班或 B 班
- **THEN** 返回 201，账号可用初始口令登录并必须改密，角色为 student 且班级正确
#### Scenario: 防止提权及非法输入
- **WHEN** 注册提交 teacher 角色、class_id、重复用户名或非 A/B 班级
- **THEN** 返回 400 或重复的 409，不新增越权账号

### Requirement: 强制首次改密
系统 MUST 在初始口令账号登录后引导个人信息改密，只允许身份、改密和登出；材料列表、详情、文件与知识库接口 MUST 在服务端拒绝。
#### Scenario: 首次登录限制
- **WHEN** 首次账号登录并绕过页面直接调用业务 API
- **THEN** 返回 403 password_change_required，页面进入改密流程，不暴露本班或跨班材料

### Requirement: 个人信息及安全改密
系统 MUST 仅展示可信用户名、角色和班级。修改密码 MUST 需要身份和 CSRF；非首次用户须校验当前密码，新密码与确认一致、8–72 字节且包含字母数字、不同于当前密码及 123456。不得修改角色或班级，不得存储或输出明文密码。
#### Scenario: 修改成功及全部会话撤销
- **WHEN** 提交有效改密
- **THEN** bcrypt 哈希更新、首次标记清除、全部旧 Session 失效并要求重新登录，新密码成功，旧密码失败
#### Scenario: 错误输入及越权
- **WHEN** 未登录、缺 CSRF、当前密码错误、弱密码、确认不一致或附带角色班级字段
- **THEN** 返回 401、403 或 400，不改变凭据或身份
#### Scenario: 凭据并发安全
- **WHEN** 登录与重置或改密并发
- **THEN** 改密完成后不存在能继续使用旧凭据创建的有效 Session
