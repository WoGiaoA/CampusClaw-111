# Proposal

## Why

教师目前只能上传、查看和下载教学材料，没有清理重复文件或撤回错误资料的入口。材料已关联 MySQL 全文与切片、Qdrant 向量、第 5 课应用绑定及历史会话引用，单独删除文件或隐藏列表会造成错误检索和失效链接。

## What Changes

- 增加教师本班材料删除 API 和材料行内黑色图标加文字的删除操作，保留查看、下载。执行前展示材料名称及不可撤销、检索退出、应用解绑的影响，允许取消。
- 删除受服务端教师身份、班级和 CSRF 校验保护；学生不能通过直接调用接口删除。
- 以持久化删除状态立即撤销材料可见性、知识库/切片访问、检索资格、重建资格及应用绑定。使用持久化清理任务最终清除全文、切片、索引任务、原文件与 Qdrant 向量；失败可重试，重启可恢复。
- 协调进行中的索引和资料使用，防止删除后后台任务重写向量或重新标记 ready。明确已在生成中的回答和已完成历史正文的保留边界。
- 历史会话保留已生成正文及引用编号，已删除来源标记“材料已删除”，禁用原文/片段入口；已打开页面点击过期来源时也提供明确反馈。
- 更新 OpenAPI、隔离测试及人工验收说明，真实 Chat/Embedding 调用均为 0。不操作现有教学资料，不启动或重建主部署。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `teaching-materials`：增加材料撤回、关联资源清理与失效来源展示；保留存续材料的查看、下载和引用回查。

## Impact

影响 `internal/campus/materials.go`、数据库增量迁移、`indexer.go`、`retrieval.go`、应用资料绑定、`ai_conversation.go`、原文读取与存储对账、`web/app.js`/样式、OpenAPI 及测试。沿用 Go/MySQL/Qdrant/原生前端；不增加外部服务、回收站或批量删除。

现行主规格保留第三课“不包含向量”的历史描述；实际检索和 AI 会话行为来自未归档第 4、5、6 课 change。本变更增量以当前实现为基线，不归档、合并或重写这些历史 change。规划产物待用户 Review 后实施。
