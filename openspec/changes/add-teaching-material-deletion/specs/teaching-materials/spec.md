# 教学材料删除增量

## ADDED Requirements

### Requirement: 教师本班材料删除权限

系统 MUST 提供受现有认证和首次改密门禁保护的 DELETE /api/materials/{id}。仅本班教师携带同会话有效 CSRF 才能删除；身份和班级 MUST 来自服务端。匿名返回401，学生或缺失/错误CSRF返回403，外班或不存在的ID均返回404。拒绝请求 MUST 不改变任何材料、绑定、索引或文件。

#### Scenario: 教师删除与越权对照
- **WHEN** 本班教师、学生、外班教师及匿名用户分别请求删除同一测试材料
- **THEN** 仅有有效CSRF的本班教师请求被受理，其余按约定拒绝且不泄露他班信息

### Requirement: 明确且可取消的删除确认

教师材料行 MUST 在现有查看和下载旁提供黑色图标加文字的删除操作。删除前 MUST 弹窗展示所选材料名称、不可撤销、退出知识库检索及失去AI应用有效绑定的影响，并提供取消和确认删除。学生 MUST 不显示删除入口；标题 MUST 按纯文本显示。提交中 MUST 禁用重复操作，结果 MUST 区分未受理、已受理待清理和已完成。

#### Scenario: 取消不产生写请求
- **WHEN** 教师打开删除弹窗后点击取消或按Escape
- **THEN** 弹窗关闭，焦点返回触发按钮，不发送DELETE且列表不变

#### Scenario: 删除后刷新失败
- **WHEN** 删除已受理但后续列表刷新失败
- **THEN** 页面说明删除已受理、列表刷新失败并提供刷新入口，不提示重新执行删除或显示材料仍然有效

### Requirement: 删除材料立即退出所有有效资料入口

删除受理提交后，材料 MUST 不再出现在材料/知识库列表、应用可选绑定及新检索候选中；全文、文件、切片及重建 MUST 不再可用。系统 MUST 移除该材料所有应用绑定，拒绝再次绑定。keyword、vector、hybrid、单轮问答及会话检索 MUST 排除已删除材料，即使向量服务返回残留候选也不能读取其文本。

#### Scenario: 存续材料不受影响
- **WHEN** 教师删除一份已绑定、已索引材料，之后查询列表、访问旧URL、检索和读取应用配置
- **THEN** 该材料及绑定不可用，本班直接访问返回410及material_deleted，外班访问仍为404；其他材料查看、下载和引用回查保持正常

#### Scenario: 无资料绑定的应用继续使用
- **WHEN** 应用最后一份绑定资料被删除，学生创建或继续会话
- **THEN** 应用按现有无绑定语义生成无资料引用的回答，不隐式扩大到全班资料

### Requirement: 关联资源持久化清理和恢复

系统 MUST 清理已删除材料对应的原文件、MySQL全文/切片/索引任务及Qdrant向量，保留无正文的最小删除标记供权限判断和历史来源提示。若外部清理未完成，MUST 持久化任务并在服务运行和重启后重试；只有所有清理经确认才报告完成，不能静默放弃或恢复资料可见性。删除流程 MUST 不调用Chat或Embedding。

#### Scenario: 返回可核对的清理状态
- **WHEN** 教师DELETE被受理但关联清理尚未全部完成，或已确认全部清理完成
- **THEN** 前者返回202、status=cleanup_pending，后者返回200、status=deleted；重复删除返回该材料当前状态且不重复创建任务

#### Scenario: 外部故障及重启恢复
- **WHEN** Qdrant或文件删除失败，或进程在任一清理步骤后中断再启动
- **THEN** 材料持续不可用，清理任务保留并幂等续做，恢复后只清除该班级该材料资源，其他文件及向量不变

### Requirement: 删除与索引及新请求的并发边界

系统 MUST 阻止删除中的材料被补索引、重建、重新绑定或重新发布为ready。已开始的索引 MUST 在清理最终完成前终止其写入；清理完成后不得出现该材料新向量。删除提交后开始的资料请求 MUST 排除该材料。已在删除前发送给模型的上下文不承诺撤回，但保存或回放的引用 MUST 反映删除状态。

#### Scenario: 索引进行时删除
- **WHEN** 测试材料处于pending/running，教师确认删除且索引调用稍后返回
- **THEN** 材料不恢复ready、不重新进入索引队列，所有可能的迟到向量最终清除，服务重启后也不复活

### Requirement: 历史来源失效明确展示

系统 MUST 保留已生成的历史会话正文和引用编号。对已删除来源，回放 MUST 返回明确的material_deleted来源状态；界面 MUST 显示“材料已删除，原文与引用片段不可用”，不提供可点击原文或片段。失效引用附件 MUST 不返回原文、完整片段或摘录。存续材料重建后的切片失效 MUST 与材料删除区分，仍可回查存续原文。

#### Scenario: 删除后恢复已有会话
- **WHEN** 学生重新打开引用过该材料的本人会话
- **THEN** 历史回答保持不变，对应编号显示已删除提示，没有错误替代来源或残留片段

#### Scenario: 已打开页面的旧引用被点击
- **WHEN** 来源展示后教师删除材料，学生点击页面仍显示的原文链接
- **THEN** 页面按material_deleted显示明确失效提示，不显示其他材料、不无限加载且不暴露内部错误

### Requirement: 删除验收及接口契约

系统 MUST 在OpenAPI中说明删除权限、CSRF、状态码、清理状态和历史来源状态，并以隔离数据验证删除、并发、失败恢复及旧查看下载流程。主部署和真实教学材料 MUST 不被测试删除，真实课程Chat和Embedding调用 MUST 均为0。

#### Scenario: 隔离验收证据
- **WHEN** 执行本变更验证
- **THEN** 留存双班角色拒绝、应用解绑、三模式排除、向量清理、原文件清理、历史失效、索引并发及失败恢复结果，区分替身与真实本地依赖
