# Proposal

## Why

现有界面把资料管理、检索和问答集中在单页，教师和学生缺少独立任务入口。阶段验收需要清楚展示应用、模板、知识库、Skill、MCP 各自的操作路径，同时保持第四课真实功能可用。

## What Changes

- 保留共用账号登录，根据服务端身份打开教师工作台或学生学习首页。统一品牌顶栏、角色导航和主内容区域。
- 将教师应用配置、知识库、MCP、作业和审计分区，将学生助手、资料检索、作业、错题和学情分区。
- 保留真实资料上传、索引重建、列表、查看、下载、三种检索模式及单轮问答，并为新功能提供明确的未开放状态。
- 应用配置与会话界面允许查看结构预览。新业务保存、上传 Skill、多轮、流式、工具发现与调用等能力由后续独立变更交付。

## Capabilities

### New Capabilities

- `teaching-workspaces`：角色工作台、任务入口、单轮对话视图及能力状态。

### Modified Capabilities

- `teaching-materials`：在角色工作台中调整材料页布局和入口，明确列表、上传、检索和出处交互。

- 根据第二轮审查增强语义配色和导航，差异化师生首页，并将教师应用配置与学生对话改为可继续扩展的工作区。

## Impact

影响原生 SPA 页面、样式、导航、前端测试和使用说明。沿用现有 Go API、Nginx 路由回退、MySQL、Qdrant 和权限。保留旧入口与来源链接。范围限于 UI、规约与回归验证，无数据库迁移、后端接口、依赖替换、主服务启停或最终 PDF。


## 交互修订（用户已授权实施）

本节取代前文关于配置预览、只改前端和后续业务另开变更的历史边界。第5、6课现已接通，本轮在本 change 内补齐新增应用和删除本人会话的真实接口；不归档其他 change，不消费真实模型额度。
- 教师首页显示真实启用应用数和 MCP 连接状态，失败明确展示。
- 新建应用采用教师同班 POST 接口，默认停用、无绑定，创建后进入配置。
- 通用顶部成功 Toast（渐入0.5秒、停留1秒、渐出0.5秒）；错误留在表单可读，未修改不发送保存请求。
- 启停使用 Switch，多选绑定使用左侧复选框；提示词、共享模板与 Skill 管理分组，标明共享影响和应用绑定状态。
- 资料绑定支持搜索、筛选结果全选/取消、已选总数和独立滚动，筛选不丢失其他选择。
- 历史会话两行标题、选中背景和可键盘/触屏操作的删除入口；确认后服务端软删除，当前会话删除后回到空态。
- 引用默认收起为来源编号与标题，展开保留真实完整片段、偏移和原文入口。


## 应用生命周期与Skill展开面板补充

用户授权：Skill编辑及原文展开区增加浅灰底/细边框；应用基本配置明确启用开关与删除。停用语义改为学生不可新建、不可在既有会话继续发送；删除为软删除并保留历史/审计。该规则覆盖第5课既有“停用后旧会话可继续”的历史行为，本轮不修改历史change。
