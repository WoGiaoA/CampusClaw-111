# Design

## Context

现有原生 SPA 用路径分发整页，`web/app.js` 集中认证、账号、材料和 RAG。现有 DOM 回归覆盖 Bearer/CSRF、文件上传、出处、失败提示。第四课在途规约定义服务端检索和问答。教师原型 01–18 已逐张参考，采用其功能层级；采用真实账号登录以及 CampusClaw 自己的北大红、中性色、表单和反馈语言。

## Goals / Non-Goals

**Goals:** 将旧功能移入按角色组织的工作台，保留直达链接和服务端权限，为未来业务定义页面边界与状态。

**Non-Goals:** 改造模型、后端接口、数据库、服务部署或用示例数据建立新的业务状态。无前端框架迁移。

## Decisions

1. **单站点和现有导航协议。** 使用真实链接与现有 SPA fallback，统一加载服务端身份，渲染品牌顶栏、角色侧栏和主区。登录成功后进工作台，首次改密仍进账号页。旧 `/materials` 按角色显示相应资料页并保留 `material_id/chunk_id`。未知路径和跨角色路径显示可返回的提示，不加载业务数据。页面刷新可恢复路径，浏览器前进后退用原生行为。分离两个站点会重复认证和组件，客户端全量路由也会增加历史与异步清理成本。
2. **统一导航与真实能力拆分。** 教师依序展示工作台、AI 应用管理、知识库管理、MCP 工具管理、作业管理、审计与统计。学生依序展示学习首页、AI 助手、讲义与检索、我的作业、我的错题、学情分析。教师知识库提供资料管理、检索及真实问答入口，学生资料页提供检索和来源，学生助手承载单轮问答。首页用真实班级身份和任务入口，避免额外接口或演示统计。
3. **真实请求与预览隔离。** 应用配置页用可切换的预览目录和基本信息、提示词/模板、Skill、知识库、MCP 配置分区，可浏览布局并看到缺失服务的说明。应用示例标为预览，不持久化，不用选中的预览修改真实问答。MCP 预留列表、详情、登记、连接与断开、发现、失败与审计区域，操作显示暂未开放。无服务时显示暂未开放，不用「暂无数据」暗示查询成功。无可用配置或真实接口返回空时分别使用「未配置」「暂无数据」。
4. **复用现有前端请求与渲染。** 保持 `/api/me`、登录、退出、注册、密码、材料上传和重建、受保护文件和切片、`/api/search`、`/api/ask` 的参数与凭据行为。材料检索独立于会话视图。单轮助手显示本次问题、真实应答及引用，示例问题只填输入框。取消可以中止浏览器等待并忽略迟到结果，提示其影响范围。会话历史、流式输出、技能与工具过程用真实状态文字表示待开发。避免写入模拟数据或引入虚构 API。
5. **保持稳定的组件契约。** 用共享页面标题、状态、导航、卡片、表单、来源对话框和反馈函数，动态字段安全文本渲染。优先主页面滚动，材料长列表允许内部滚动。响应式将侧栏和主内容改为上下流动布局，支持 1463×775、1280×720 及窄屏。原型 07/08/14/15/18 对应保留教学扩展入口；16/17 仅参考空态与问答布局，关怀式应用可作带标签的预览。

6. **第二轮视觉与页面结构。** 北大红用于品牌、选择和主操作，蓝色用于引用和处理提示，绿色用于已可用与成功，橙色用于警告或待配置。侧栏使用同一笔画的本地 SVG。教师首页用本班材料真实总数和配置状态安排快捷任务，学生首页以提问和讲义为主。教师应用使用列表与分区配置，开放浏览与本地草稿预览，保存、上传与绑定保持禁用。学生助手采用应用栏、会话侧栏、消息区和底部输入，重置当前问题只清本页，不创建服务端会话。历史、流式和工具过程保留明确入口或说明。

7. **紧凑标题与学生对话。** 工作台共享同行标题和说明，空间不足时自然换行。首页保留原入口结构，紧凑处理欢迎区标题行。学生助手在常见视口中用弹性布局分配剩余高度，桌面会话栏与消息区独立滚动，输入区保留在底部。过矮视口允许页面滚动。新对话只重置本页。输入按内容增长且封顶。引用收起时最多三行摘要，展开使用问答接口已返回的完整切片及偏移，原始文件名从现有材料列表补齐，失败时保留材料标题和回查入口。

## Risks / Trade-offs

- 旧材料页曾同时提供问答与检索，拆分后保留明确入口和直达来源，验证长标题、异常来源及跨班拒绝。
- 不同页面的并行请求可能在 401 或离开页面后返回，复用认证错误处理，并避免迟到响应覆盖当前视图。
- 浏览器检查可用隔离的 HTTP 响应夹具验证视觉和状态，需标注夹具。真实模型、主服务和历史部署证据分别记录，遵循现有网关限额。

## Migration Plan

只替换前端静态资产并更新缓存版本。回滚以本变更涉及的前端资产为单位，保留已有工作区修改与业务卷。规约审阅和严格校验完成后进入 Apply，验证通过的任务才勾选。


## 当前实施设计（覆盖历史预览边界）

1. POST /api/ai/apps 只接受 name；校验1–100码点，教师+CSRF，同班服务端赋值，enabled=false，空提示词和空绑定，返回201完整配置。沿用现有 PATCH 配置及模板引用语义。
2. DELETE /api/ai/conversations/{conversation_id} 仅学生本人同班+CSRF。新增可重复迁移的 deleted_at，列表、详情与发送预检统一排除软删除行；事务锁会话，running 轮次返回409，避免生成/删除竞态。保留消息、引用和工具审计，成功返回200 deleted，再次或他人访问404。删除不触发模型调用。
3. 保存按钮按字段/集合快照判断 dirty，未修改禁用并显示未修改；保存中禁用，成功Toast，失败保留草稿及行内错误。分区/应用切换有未保存草稿时弹窗确认，取消留在原处。应用提示词和绑定模板一起保存，模板正文独立保存，共享模板修改提示影响所有绑定应用的后续回答；另存只创建，仍需选择并保存绑定。
4. 通用成功Toast由setStatus的success路径统一调用；状态节点保留文本供无障碍及流程查询、视觉隐藏成功消息，无挤占布局。错误不自动消失，减少动态效果偏好禁用动画。
5. 复用原生checkbox，role=switch语义用于启停；标签与输入一行。Skill绑定状态与全班启用状态独立展示。编辑及替换按需展开，上传新Skill使用明确入口。
6. 绑定列表Set维护草稿，资料本地搜索及筛选结果全选只变更可见项，保存全部选择。资料选数含隐藏项。资料/Skill列表限高滚动，窄屏按钮换行。
7. 删除对话使用原生dialog确认，默认聚焦取消，失败留弹窗；会话操作在hover/focus-within显示，触屏始终可见。删除成功后重读列表，失败不伪装成功刷新。引用使用原生details，收起只显示来源编号和资料标题，展开后完整片段、偏移和原文链接。


## Skill 文件选择样式补充

新增与替换共用紧凑文件选择卡：上传图标、选择/更换文件文案、文件名与格式/大小说明分行，原生文件输入透明覆盖以保留键盘和系统文件对话框。文件名安全文本渲染，长名称换行，上传按钮独立右对齐。保持原接口及上传行为。


## Skill 容量放宽（覆盖先前32 KB限制）

用户授权按常见Skill规模放宽：文件128 KB（131072字节），总文本40000 Unicode码点，规程正文30000码点；multipart请求额外留8 KB封装预算。主流最佳实践推荐主SKILL.md少于500行而非统一字节上限（https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices），128 KB是本项目的宽松工程限制。保留课程TXT/MD头字段格式，不在本次增加标准Skill目录导入能力。

skills.raw_text和procedure_text升级MEDIUMTEXT，迁移按information_schema检查类型，可重复执行并保留原数据；同时调整解析与上传读取上限、页面说明、接口文档和边界测试。不截断已上传正文，模型请求仍带完整命中规程，输出预算保持不变。


## 应用生命周期与Skill面板（当前规则）

- Skill“编辑配置”和“查看上传原文”的展开内容使用独立浅色面板（#fcfcfd背景、line-strong细边框和圆角）。折叠标题留在外侧，原文作为编辑区的同级操作，各自可独立展开。
- 基本配置的开关改称“启用应用”，明确停用后学生列表移除、旧会话只读。每次接受新消息事务中锁定并检查当前应用enabled及deleted_at；停用/删除返回403 app_disabled，预检失败不插入轮次、不调用模型。工具执行前同样检查当前启用与未删除；停用前已受理的文本生成可结束，不声称即时取消所有在途请求。
- assistants增加deleted_at。DELETE /api/ai/apps/{app_id}仅本班教师+CSRF，事务锁应用；存在running轮次返回409，成功标记deleted_at并enabled=false，200 deleted。列表、配置更新与工具授权接口排除已删行，重复/跨班404。保持绑定、Skill、材料、会话和审计，以保留证据；预置builtin_key也保留，重复迁移不能复活已删除应用。
- 学生已停用应用的历史可读，发送框/按钮禁用，提示仅供查看。浏览器重新获得焦点或可见时刷新应用列表，服务端仍拒绝旧页面直接请求。删除需确认，失败不移除列表；删除当前应用后选择下一个，空列表显示新建入口。
