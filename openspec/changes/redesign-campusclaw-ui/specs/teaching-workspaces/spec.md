# Spec Delta

## Purpose

为教师和学生提供各自可导航、可直达的班级教学工作台，在共用的品牌界面中承载已上线能力及后续课程模块的入口，并向用户明确反馈当前可用范围。

## ADDED Requirements

### Requirement: 角色工作台与访问入口

平台 MUST 提供共用登录入口，并根据服务端会话身份渲染品牌顶栏、角色导航、班级信息及主内容区。首次改密门禁、会话失效和退出语义 MUST 保持有效。

#### Scenario: 教师工作台
- **WHEN** 已登录教师进入工作台
- **THEN** 能进入首页、AI 应用管理、知识库管理、MCP 工具管理、作业管理、审计与统计，并能访问个人信息与退出

#### Scenario: 学生工作台
- **WHEN** 已登录学生进入工作台
- **THEN** 能进入学习首页、AI 助手、讲义与检索、我的作业、我的错题及学情分析，并能访问个人信息与退出

#### Scenario: 未授权和首次改密
- **WHEN** 未登录、会话失效、需首次改密或尝试直达其他角色专属页面
- **THEN** 页面按对应状态引导至登录或改密，或显示不可访问及返回入口，且不加载该页面的业务数据

### Requirement: 教师 AI 与 MCP 配置入口

教师工作台 MUST 区分应用配置预览与实际能力。预留内容 MUST 使用明确的状态和原因。

#### Scenario: 查看应用配置
- **WHEN** 教师选择任一带预览标识的应用
- **THEN** 可以浏览基本信息、角色提示词和模板、内置及上传 Skill、知识库与工具绑定区域，并能识别尚未开放的保存、启停与上传

#### Scenario: 查看工具和教学管理
- **WHEN** 教师打开 MCP、作业或审计页
- **THEN** 可识别该页未来承载的操作及数据，并看到未开放原因，不出现虚假的连接、发现、评分、统计或记录

### Requirement: 学生单轮问答

学生助手 MUST 以现有真实单轮资料问答为可用模式，明确区分未来的会话历史、流式输出、应用路由、Skill 与 MCP。

#### Scenario: 提问、引用与建议
- **WHEN** 学生选择推荐问题并提交
- **THEN** 推荐问题先填入输入框，提交发起既有问答请求，并呈现实际回答或错误以及可打开的真实出处

#### Scenario: 取消浏览器等待
- **WHEN** 请求进行中用户取消等待
- **THEN** 界面结束等待且迟到结果不覆盖新一轮，文案说明取消作用于浏览器侧

#### Scenario: 浏览其他应用或学习入口
- **WHEN** 学生浏览预览应用、历史区域或作业、错题、学情分析
- **THEN** 可辨认能力未开放，不产生模拟回答、历史、成绩或学习画像

### Requirement: 状态与交互一致性

工作台 MUST 对实际可用操作提供加载、失败、成功或空状态反馈。未配置、无数据和未开放 MUST 使用符合实际来源的提示。

#### Scenario: 可用与预留操作
- **WHEN** 用户切换导航、使用表单、打开或关闭弹窗、查看预留功能
- **THEN** 活动导航可辨认，表单支持键盘与可见焦点，弹窗有关闭路径，失败可恢复，预留操作不发业务请求且不给出成功反馈

### Requirement: 按角色组织首页与统一状态

工作台 MUST 使用统一线性导航图标和带文字的语义状态。教师首页突出管理，学生首页突出提问与浏览讲义。

#### Scenario: 首页任务入口
- **WHEN** 用户打开工作台首页
- **THEN** 教师可见现有材料接口返回的计数或加载失败状态，并能进入资料和配置；学生可直接进入资料问答和讲义检索，预留能力不显示虚构统计

### Requirement: 分区配置和对话工作区

应用管理 MUST 支持从应用列表进入分区配置预览。学生对话 MUST 划分应用控制、会话、消息与输入区域。

#### Scenario: 管理预览
- **WHEN** 教师选择应用与配置分区
- **THEN** 可查看基本信息、模板、技能、知识库和 MCP 对应控件，未接入的写操作禁用，不发写请求

#### Scenario: 学生使用对话
- **WHEN** 学生打开可用助手、提交问题或清空当前问答
- **THEN** 应答与引用来自既有接口，清空只改变当前页面，历史、流式和工具区域不会生成虚构内容

#### Scenario: 紧凑标题和消息区
- **WHEN** 用户访问师生工作台页面或调整窗口尺寸
- **THEN** 标题和说明优先同行并在窄屏换行，学生助手利用剩余高度，桌面会话栏与消息独立滚动，输入保持在底部并在上限后内部滚动

#### Scenario: 新对话与多条引用
- **WHEN** 学生点击新对话或展开任一引用
- **THEN** 新对话只清空本页状态，引用可独立切换短摘要与真实完整片段及定位，原文回查可用



### Requirement: 真实配置管理与紧凑反馈

系统 MUST 在第5、6课能力接通后使用真实数据管理应用，区分应用绑定和班级共享配置。本节覆盖上述历史预览场景。

#### Scenario: 新建及保存配置
- **WHEN** 教师新建应用或修改配置
- **THEN** 服务端验证教师、班级与CSRF，新增应用默认停用且无绑定；未修改不发保存请求，成功显示短时顶部Toast，失败保留草稿和可读错误

#### Scenario: 配置范围与草稿
- **WHEN** 教师编辑提示词、模板、Skill或资料绑定
- **THEN** 共享管理与当前应用绑定分区，提示共享修改影响；开关和复选框同行，资料搜索全选不丢失隐藏选择，离开未保存草稿需确认

#### Scenario: 真实首页
- **WHEN** 教师进入首页
- **THEN** 应用启用数和工具连接状态从本班API读取，失败显示错误而非假计数

### Requirement: 本人会话删除与来源折叠

系统 MUST 支持本人会话服务端软删除并默认收起引用，不丢失真实证据信息。

#### Scenario: 删除与隔离
- **WHEN** 学生确认删除本人会话
- **THEN** 服务端验证同班本人及CSRF，生成中返回409；删除后列表详情及发送不可见，重复或越权返回404，当前会话回空态，消息与审计保留

#### Scenario: 来源与可访问操作
- **WHEN** 学生浏览会话列表或来源
- **THEN** 标题最多两行、当前项可辨认，删除支持键盘触屏；来源默认显示编号和标题，展开保留完整片段、偏移和原文入口


### Requirement: 统一 Skill 文件选择外观

Skill 上传和替换 MUST 使用同一可访问的自定义文件选择外观，隐藏浏览器原生按钮视觉，保留原生选文件能力。

#### Scenario: 文件选择与窄屏
- **WHEN** 教师展开上传新Skill或替换文件并选择文件
- **THEN** 图标、选择文案、文件名、UTF-8/TXT/MD及128 KB限制清楚分行，选择后显示真实文件名与大小，未选择时上传禁用，长文件名与窄屏不横向溢出


### Requirement: 放宽文本Skill容量

系统 MUST 接受不超过128 KB、总文本40000码点且规程正文30000码点的合法课程格式Skill，并完整保存、替换和读取。本节覆盖前述32 KB限制。

#### Scenario: 大文件及边界
- **WHEN** 教师上传或替换超过旧32 KB的合法中文Skill，或提交超出新字节/码点限制的文本
- **THEN** 合法内容完整存取且不截断，超限返回413；数据库字段升级可重复且保留旧数据，页面统一显示128 KB


### Requirement: Skill展开内容分隔

Skill编辑和原文 MUST 作为同级独立折叠操作，展开内容带浅色背景、边框与圆角，长文本不溢出。

#### Scenario: 独立展开
- **WHEN** 教师展开编辑配置或查看原文
- **THEN** 内容位于独立面板内，原文不再嵌套在编辑表单中，两者可独立展开收起

### Requirement: 应用删除和完整停用

系统 MUST 提供本班教师应用启停与服务端软删除；停用后学生不能发起新会话或在旧会话继续发送。本节覆盖此前停用旧会话可继续的行为。

#### Scenario: 停用与学生直调
- **WHEN** 教师停用应用而学生仍持有旧页面或会话ID
- **THEN** 学生应用列表移除此项，旧历史只读，发送API返回403 app_disabled，不建立新轮次或调用模型；后续工具派发重新校验应用启用状态

#### Scenario: 删除、隔离与重启
- **WHEN** 本班教师确认删除应用，或他班/学生/缺CSRF请求删除
- **THEN** 本班合法删除标记deleted_at并停用，生成中返回409；越权按403/404拒绝，重复删除404，历史/绑定/审计保留，重复迁移不重新创建预置应用
