# Spec Delta

## MODIFIED Requirements

### Requirement: 页面视口适配

页面 MUST 使用 68px 桌面顶栏并移除底部课程说明。登录、个人信息和工作台 MUST 随可用视口布局。内容超出时 MUST 可通过滚动访问，不得横向溢出或裁掉输入、操作按钮。

#### Scenario: 桌面窗口布局
- **WHEN** 以 1463×775 或 1280×720 窗口打开登录页或教师、学生材料页
- **THEN** 顶栏高 68px，无课程页脚，登录表单完整显示，侧栏与内容可同时访问，材料列表超量时可在列表区域滚动

#### Scenario: 窄屏或低高度窗口
- **WHEN** 缩窄窗口或降低可用高度，并使用登录、个人信息和材料页面
- **THEN** 布局适配窗口，导航、字段和按钮可访问，无横向溢出

### Requirement: 统一平台视觉与交互反馈

前端 MUST 使用北大红 #9B0000、中性页面和统一组件。教师知识库和学生讲义页 MUST 展示文件层次及次级查看和下载操作。上传仅主按钮突出。表单、文件选择、加载、成功和失败反馈 MUST 可访问，并保留现有接口与权限。

#### Scenario: 材料工作区与操作层次
- **WHEN** 教师或学生打开材料页
- **THEN** 主内容在最大 1440px 范围内，标题、元信息和操作层次清晰，查看和下载采用次级样式，学生无上传入口，长标题不挤出操作

#### Scenario: 文件选择与异步反馈
- **WHEN** 选择文件、上传或刷新列表
- **THEN** 展示文件名和大小，加载时禁用对应按钮并提供忙碌提示，结束后恢复，成功与失败可区分，继续使用原有 multipart 和 CSRF

#### Scenario: 全站表单与正文交互
- **WHEN** 使用登录、注册、个人信息或查看正文
- **THEN** 字段、错误及焦点状态一致，请求参数和改密规则保留，正文安全显示，弹窗支持关闭按钮和 Escape 并移除临时节点

## ADDED Requirements

### Requirement: 工作台材料检索与来源兼容

教师和学生 MUST 从各自的材料入口使用真实资料列表和三种检索模式。旧材料地址、受保护下载与来源深链接 MUST 保持可用。

#### Scenario: 访问现有来源链接
- **WHEN** 从问答或搜索结果打开切片，或直接进入带材料和切片标识的旧地址
- **THEN** 通过现有受保护接口显示本班原文、切片和坐标，越权或已失效来源显示失败而不展示数据

#### Scenario: 使用知识库
- **WHEN** 教师上传、刷新索引状态或重建索引，或师生发起检索
- **THEN** 使用现有接口及权限，显示真实状态，检索空结果与依赖故障可区分，学生不能执行教师写操作
