# Knowledge Retrieval Spec Delta

## Purpose

让 CampusClaw 本班教师和学生用自然语言定位已上传教学材料中的相关片段，并通过材料标题、切片序号、字符位置和摘录核对原始依据。检索必须沿用现有可信会话和班级边界，区分正常空结果与索引或外部服务故障，不引入另一套认证，也不损害原材料的查看与下载。

## ADDED Requirements

### Requirement: 检索身份与班级边界

系统 MUST 对搜索、索引状态、切片来源和重建接口复用现有服务端认证及首次改密门禁。教师与学生 MUST 只能检索所属班级；搜索范围 MUST 仅取自可信身份，忽略客户端提供的角色、用户和班级选择值。所有候选路径、正文回取和来源读取 MUST 校验相同班级。

#### Scenario: 匿名或失效会话
- **WHEN** 无有效Session请求任一新增受保护接口
- **THEN** 返回401，不返回标题、正文、来源、索引状态或向量数据，也不发起嵌入请求

#### Scenario: 首次改密门禁继续有效
- **WHEN** must_change_password为真的已登录用户请求搜索、来源或索引接口
- **THEN** 返回403及password_change_required，不能以新增接口绕过改密

#### Scenario: 同班教师与学生共享检索
- **WHEN** 已完成改密的A班教师和学生搜索仅存在于A班已就绪切片的原词
- **THEN** 两者都可获得本班命中，不因上传者不同而拒绝学生读取

#### Scenario: 伪造身份不能扩大范围
- **WHEN** A班用户在JSON、query或请求头携带B班class_id、其他user_id或teacher角色搜索B班专属内容
- **THEN** 实际检索仍限A班，返回200及空hits，不返回B班材料信息

#### Scenario: 向量候选回表再次核对
- **WHEN** 向量候选错误地包含B班、已删除或非ready的切片ID
- **THEN** 回表过滤掉这些ID，结果不包含其正文、标题、摘录或来源链接

### Requirement: 可定位的自动切片

系统 MUST 以已保存的正文生成不超过800个Unicode码点的切片，非末片与后续片重叠80个码点，优先在可用空行、换行或句号处断开；窗口必须前进。切片序号 MUST 从1连续编号，字符区间 MUST 为正文Unicode码点的零基左闭右开区间，切片文本 MUST 等于该区间正文。切分 MUST 不修改原文件和已保存正文。

#### Scenario: 中文长文切片及定位
- **WHEN** 对包含中文、emoji、CRLF和多段内容的正文建立索引
- **THEN** 每片文本均为有效文本、长度不超过800码点，区间和正文逐片一致，首末内容被覆盖且无无限循环
- **AND** 按句段边界产生的非末片长度大于80，下一片从前片末尾向前80码点开始

#### Scenario: 短文本与无断点长文
- **WHEN** 分别索引小于等于800码点的正文和没有句段断点的长正文
- **THEN** 短正文生成一片，长正文按窗口上限切开并保留约定重叠，不丢失尾部

### Requirement: 索引状态与原文保留

系统 MUST 在材料保存提交后独立建立索引，并提供本班可读的pending、running、ready、failed状态。仅ready批次的切片 MUST 可检索；所有切片的嵌入与向量写入确认成功后才能将该批次标为ready。失败或中断 MUST 保留材料与全文，不得以部分索引冒充成功，并支持恢复或教师重试。

#### Scenario: 新材料异步可检索
- **WHEN** 教师成功上传材料，索引任务随后完成
- **THEN** 上传仍返回201及原有两个ID，索引状态最终变为ready，本班搜索可命中该材料

#### Scenario: 嵌入或向量写入失败
- **WHEN** 索引中某批嵌入失败、维度不符或向量写入无法确认
- **THEN** 状态变为failed且该批切片不进入任何检索结果，原文件与全文仍可按现有权限查看下载
- **AND** 响应和日志不暴露密钥、外部原始错误体或内部路径

#### Scenario: 进程中断后恢复
- **WHEN** 索引处于running时服务中断并重新启动
- **THEN** 未完成任务被恢复为可重试状态或明确失败，不长期停在running；重复处理不产生重复可见切片或错误ready状态

### Requirement: 教师重建与已有材料补索引

系统 MUST 允许本班教师携带有效CSRF通过POST /api/materials/{id}/reindex请求默认策略重建，返回202及任务状态；同材料已有活动任务时 MUST 返回409。重建 MUST 使旧批次不再可检索并清理旧向量和切片，保持原材料ID与正文。所有既有材料 MUST 可补索引，默认种子和无索引材料 MUST 能幂等登记索引任务。

#### Scenario: 教师重建本班材料
- **WHEN** 本班教师带有效CSRF对ready或failed材料请求重建
- **THEN** 返回202，旧批次退出检索；任务完成后新切片可用，旧ID不能再返回来源正文，原材料与文件保持不变

#### Scenario: 拒绝学生和缺失CSRF
- **WHEN** 学生请求重建，或教师携带缺失/错误CSRF请求重建
- **THEN** 返回403，不创建任务、不改变旧索引、正文或文件

#### Scenario: 跨班与不存在的材料
- **WHEN** 教师请求重建其他班级材料或不存在的材料
- **THEN** 两者均为404，不暴露他班索引状态或内容

#### Scenario: 并发重建及重启补齐
- **WHEN** 同材料已有pending/running任务时再次请求重建，或服务重复登记既有无索引材料
- **THEN** 前者返回409且不产生第二个活动任务；后者只生成一个有效任务，不重置账号、不重复材料

### Requirement: 搜索输入与确定的响应边界

系统 MUST 提供POST /api/search，接受application/json单一对象，q去首尾空白后为1至500个Unicode码点，mode为keyword/vector/hybrid且默认hybrid，limit为1至20的整数且默认10。请求体 MUST 不超过16KiB；无效输入返回400。合法搜索 MUST 返回200及q、mode、hits、message，hits为空时message为“资料中未找到相关内容”。

#### Scenario: 默认模式与空结果
- **WHEN** 合法本班用户只提交有效q，且没有达到该模式过滤条件的本班候选
- **THEN** 返回200、mode=hybrid、hits=[]及固定未找到提示，不编造来源或调用生成模型

#### Scenario: 非法输入不访问外部服务
- **WHEN** q为空白/超长，mode非法，limit非整数或越界，JSON多值/尾随垃圾、超限或媒体类型非法
- **THEN** 返回400，不查询候选、不调用嵌入或向量服务

### Requirement: 关键字检索

keyword模式 MUST 仅对本班ready切片作中文全文检索，按正的全文相关度降序返回，分数相同时按切片ID升序。该模式 MUST 不调用嵌入、向量或生成服务；即使向量服务不可用，已有ready文本仍可用于关键字检索。

#### Scenario: 原词命中及外部依赖隔离
- **WHEN** keyword查询本班ready切片中的可索引中文原词，而向量库或嵌入服务不可用
- **THEN** 返回200及可追溯命中，外部服务调用次数为0

#### Scenario: 非ready切片不命中
- **WHEN** 同一关键词只出现在本班pending/running/failed批次的切片
- **THEN** 返回200空hits，不因正文已存储就当作索引就绪

### Requirement: 向量检索

vector模式 MUST 使用与索引兼容的模型嵌入问句，在查询时限定班级，只保留余弦相似度大于等于0.35且回表后属于本班ready批次的切片；按相似度降序、ID升序排序。嵌入或向量服务不可用、维度错误时 MUST 返回503，不填造向量或分数。

#### Scenario: 语义改写命中
- **WHEN** 问句原词不同但嵌入候选与本班就绪切片相似度达到0.35
- **THEN** 返回来自MySQL的切片正文及来源；关键词路径无命中不影响vector模式

#### Scenario: 低分与依赖失败不同
- **WHEN** 候选全部低于0.35，或嵌入/向量服务失败
- **THEN** 前者为200空hits，后者为503服务暂不可用，不能把故障当作无资料

### Requirement: 混合检索与稳定排序

hybrid模式 MUST 分别执行关键字与向量检索，各取最多40条经过各路阈值和本班ready回表校验的候选，按过滤后的名次执行RRF，k=60、rank从1起算，缺席一路贡献0；同一切片 MUST 合并，按融合分降序、ID升序截取limit条。任一路依赖失败 MUST 返回503，不能静默冒充完整混合结果。

#### Scenario: 两路融合与去重
- **WHEN** 切片X在关键词排1且向量排3，切片Y只在向量排1
- **THEN** X的融合分为1/61+1/63，Y为1/61，各自只出现一次，X排在Y之前

#### Scenario: 过滤后再融合
- **WHEN** 向量低于阈值、跨班或失效切片存在于原始候选中
- **THEN** 它们不参与名次或融合结果，保留候选重新从rank=1编号

#### Scenario: 混合依赖不可用
- **WHEN** 关键词仍可用但嵌入或向量服务失败
- **THEN** hybrid返回503并提示可切换keyword；显式keyword请求仍可正常处理

### Requirement: 命中内容溯源

每条命中 MUST 包含material_id、knowledge_entry_id、chunk_id、material_title、chunk_index、char_start、char_end、excerpt和source_url。excerpt MUST 从校验后的切片原文取前最多200个Unicode码点，source_url MUST 指向本站受保护材料详情；score及两路rank MUST 标明各自含义，不能将融合分冒充相似度或概率。

#### Scenario: 打开出处核对原文
- **WHEN** 用户点击命中的来源链接
- **THEN** 打开对应本班材料原文，材料标题与命中一致，切片区间及摘录可在该正文中核对
- **AND** 中文和emoji不造成按字节截断或位置错配

#### Scenario: 篡改来源与过期切片
- **WHEN** A班用户请求GET /api/materials/{id}/chunks/{chunk_id}中的B班、材料不匹配或已重建删除的切片ID
- **THEN** 返回404，与不存在相同，不返回旧切片或他班文本

### Requirement: 检索界面与原有功能兼容

材料页 MUST 为本班教师和学生提供问题输入、三模式选择、结果摘录及来源入口，显示加载、无命中和故障状态；教师 MUST 能看到索引状态和重建操作，学生不得拥有可用写入口。页面 MUST 安全显示不可信文本，并保留现有材料上传、查看、下载、个人信息和退出流程。

#### Scenario: 师生检索与失败反馈
- **WHEN** 师生分别使用检索界面并遇到空结果、正常命中或503
- **THEN** 分别显示固定空提示、可打开来源的结果或可读故障提示，按钮恢复可用，不把故障显示成空资料

#### Scenario: 上传已保存但索引失败
- **WHEN** 教师上传返回201后索引状态变为failed
- **THEN** 页面明确说明材料已保存、索引失败，可查看下载或重试索引，不要求重新上传文件

#### Scenario: 安全展示与旧流程回归
- **WHEN** 材料标题或正文含HTML片段，用户检索后查看详情、下载或改密
- **THEN** 内容按文本呈现不执行脚本，原有Session/CSRF/首次改密及下载权限保持有效
