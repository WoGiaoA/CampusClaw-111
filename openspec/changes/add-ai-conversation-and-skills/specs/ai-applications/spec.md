# AI 应用增量

## Purpose

让班级教师管理可供本班学生选择的教学应用，通过可复用的角色模板、可匹配的文本技能和明确的资料绑定控制每轮对话的行为及可用范围。

## ADDED Requirements

### Requirement: 班级应用与内置用途

系统 MUST 每班提供至少两个可选的内置应用。教师 MUST 能查看及配置本班应用的启停、角色指令、模板和能力绑定。学生 MUST 只能发现本班启用应用及其公开字段。

#### Scenario: 内置应用实际区别
- **WHEN** 同班学生使用「课程资料问答」与「解题引导」提交相同问题
- **THEN** 捕获的出站 system 内容或能力选择体现两者用途，解题引导要求分步提示，默认不给最终答案

#### Scenario: 授权与原子更新
- **WHEN** 学生写配置、教师访问他班应用，或本班教师提交含跨班或不存在 ID 的绑定集合
- **THEN** 分别返回 403、404 和 404，已有配置与绑定完整保留

### Requirement: 共享提示词模板

教师 MUST 能创建、编辑和绑定本班纯文本模板。同一模板 MUST 可被多应用引用。每轮实际 system 消息 MUST 包含有效角色指令及已绑定模板正文。

#### Scenario: 模板编辑在下一轮生效
- **WHEN** 两个应用绑定同一模板且教师保存新正文
- **THEN** 两者之后接收的轮次发送新正文，已完成回答保留；解绑时后续 system 不再包含模板，角色指令为空时使用服务端默认角色

### Requirement: 教师文本 Skill 生命周期

教师 MUST 能上传课程格式的 UTF-8 文本 Skill、查看解析结果、编辑适用条件、启停和绑定。本班 MUST 预置含循序提示规程的「解题引导」，规程默认禁止直接给最终答案、得数或完整解法。

#### Scenario: 上传与校验
- **WHEN** 上传合法的中文元数据与规程正文，或上传缺字段、重复字段、未知字段、非法工具名、超限或无效 UTF-8 文件
- **THEN** 合法上传返回 201 并可绑定，非法上传返回 400 或 413 且无新增记录；跨班不可读取或绑定

### Requirement: 单轮确定性 Skill 路由

系统 MUST 仅在本应用当前启用且已绑定的 Skill 中匹配当前提问。去重关键词每命中一次得一分，最高正分胜出，同分取最小 ID。模型系统消息 MUST 只额外包含胜出 Skill 的名称与完整规程，界面 MUST 显示实际命中。

#### Scenario: 命中、并列、未命中及停用
- **WHEN** 构造同分候选、无命中问题，再停用或解绑原胜者并重复问题
- **THEN** 选用结果可复算，零分时不注入 Skill，停用或解绑下一轮立即生效；请求中没有其他 Skill、匹配字段或完整原始文件
