# 工作台增量

## MODIFIED Requirements

### Requirement: 教师 AI 与 MCP 配置入口

教师工作台 MUST 保留本班 AI 应用配置与真实保存反馈，并提供本班 MCP 服务管理、应用工具授权、Skill 工具声明和审计。其他后续能力 MUST 显示明确的开放状态。

#### Scenario: 查看应用配置
- **WHEN** 教师选择本班应用
- **THEN** 可以读取、保存基本配置、角色提示词和模板、内置及上传 Skill、知识库绑定及工具授权

#### Scenario: 查看工具和教学管理
- **WHEN** 教师打开 MCP、作业或审计页
- **THEN** 可登记、连接、断开和查看真实发现清单，审计展示本班实际事件；作业入口保留未开放原因，无虚构评分、统计或记录

### Requirement: 分区配置和对话工作区

应用管理 MUST 支持从应用列表进入分区配置。学生对话 MUST 保留应用控制、会话、消息与输入区域，并能查看自己的工具状态。

#### Scenario: 管理预览
- **WHEN** 教师选择应用与配置分区
- **THEN** 可使用基本信息、模板、技能、知识库及 MCP 工具授权控件，断开或失效绑定有可辨认状态

#### Scenario: 学生使用对话
- **WHEN** 学生打开助手、创建或恢复会话并提交问题
- **THEN** 应答与引用来自会话接口，界面区分空、加载、流式、失败和已保存状态；工具过程只显示本人会话实际发生的受控事件

#### Scenario: 紧凑标题和消息区
- **WHEN** 用户访问师生工作台页面或调整窗口尺寸
- **THEN** 标题和说明优先同行并在窄屏换行，学生助手利用剩余高度，桌面会话栏与消息独立滚动，输入保持在底部并在上限后内部滚动

#### Scenario: 新对话与多条引用
- **WHEN** 学生点击新对话或展开任一引用
- **THEN** 可选择启用应用创建新会话且保留旧历史；引用可独立切换短摘要与完整当轮片段及定位，同班原文回查可用

### Requirement: 学生单轮问答

学生助手 MUST 保留应用会话、真实流式响应与本人历史。既有材料页 MUST 保留单轮资料问答和来源深链接。后续学习能力继续使用预留状态。

#### Scenario: 提问、引用与建议
- **WHEN** 学生选择推荐问题并提交
- **THEN** 推荐问题先填入输入框，提交后显示实际增量或错误、命中的 Skill、工具状态及可打开的真实出处

#### Scenario: 取消浏览器等待
- **WHEN** 请求进行中用户取消
- **THEN** 界面结束等待、关闭流、区分未完成内容，重新读取会话确认保存状态；迟到事件不覆盖其他会话或轮次

#### Scenario: 浏览其他应用或学习入口
- **WHEN** 学生选择本班启用应用、恢复历史或打开作业、错题、学情分析
- **THEN** 应用与历史来自服务端；预留功能不生成虚假成绩、画像或工具过程
