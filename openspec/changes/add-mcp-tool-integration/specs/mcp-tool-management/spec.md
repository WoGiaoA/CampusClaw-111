# MCP 管理与授权

## Purpose

为班级教师提供可控的独立工具登记、发现和授权能力，确保工具端点与凭据始终由服务端约束，运行中的会话只能使用仍获授权的工具。

## ADDED Requirements

### Requirement: 班级登记与受控端点

系统 MUST 允许教师登记本班服务名称、允许列表中的 Base URL 和写入式凭据。学生不得读写管理接口。服务器 MUST 在出站前复核允许列表，拒绝重定向和任意目的地址。响应 MUST 仅给凭据配置状态。

#### Scenario: 恶意地址和跨班访问
- **WHEN** 教师登记非受控地址、访问他班服务，或学生绕过界面调用管理接口
- **THEN** 非受控地址无出站请求，跨班 404，学生 403；响应和日志不含凭据

### Requirement: 发现清单整体替换与即时失效

连接 MUST 完成初始化和发现才发布一份可用清单。重连 MUST 整体替换，失败、断开或编辑连接信息 MUST 使旧快照不可再授权。较早请求的迟到结果不得覆盖较新操作。

#### Scenario: 重连、失败和竞争
- **WHEN** 工具清单变化后重连，或发现尚未完成时教师断开
- **THEN** 成功发布仅包含当前清单，迟到发现不会恢复断开状态；错误令牌、非法 Schema 或握手失败时没有可用工具

### Requirement: 应用与 Skill 双重授权

系统 MUST 让教师管理本班应用的工具允许列表。模型候选 MUST 同时满足应用已授权、命中 Skill 已声明、会话身份有效、当前服务已连接且清单匹配。执行前 MUST 再核对这些条件和参数 Schema。

#### Scenario: 拒绝伪造与旧绑定
- **WHEN** 模型提出未授权名称，或教师在声明后断开服务、停用 Skill、解绑工具、重连发现了不同清单
- **THEN** 不派发该次调用，显示受控拒绝；已登记本班服务可归属的拒绝进入审计，外班信息不外泄
