# AI 应用增量

## MODIFIED Requirements

### Requirement: 教师文本 Skill 生命周期

教师 MUST 能上传课程格式的 UTF-8 文本 Skill、查看解析结果、编辑适用条件、启停和绑定。本班 MUST 预置含循序提示规程的「解题引导」，规程默认禁止直接给最终答案、得数或完整解法。工具声明 MUST 支持 `knowledge_search` 与 `工具名@服务器名`。新增或替换外部声明 MUST 校验本班服务与可用清单，实际调用仍须应用授权。

#### Scenario: 上传与校验
- **WHEN** 上传合法的中文元数据与规程正文，或上传缺字段、重复字段、未知字段、非法工具名、超限或无效 UTF-8 文件
- **THEN** 合法上传返回 201 并可绑定，非法上传返回 400 或 413 且无新增记录；跨班不可读取或绑定

#### Scenario: 工具声明和旧文件兼容
- **WHEN** 上传或替换 Skill，声明内置检索、本班已发现的外部工具、断开的工具、他班引用或未知工具
- **THEN** 合法声明可保存，非法声明使整个写入失败；已有无工具和仅内置检索的文件仍可读取、编辑，旧声明不会自动获得应用授权
