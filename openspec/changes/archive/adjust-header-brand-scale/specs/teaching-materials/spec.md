# Spec Delta

## MODIFIED Requirements

### Requirement: 页面视口适配
页面 MUST 使用68px顶栏并移除底部课程说明；登录和材料页面 MUST 根据可用视口布局。内容超出时 MUST 可通过内容区域滚动访问，不得横向溢出或裁掉输入、操作按钮。
#### Scenario: 桌面窗口布局
- **WHEN** 以1463x775或1280x720窗口打开登录页或教师/学生材料页
- **THEN** 顶栏高68px、无课程页脚，登录表单完整显示，材料列表超量时在列表区域滚动
#### Scenario: 窄屏或低高度窗口
- **WHEN** 缩窄窗口或降低可用高度，并使用登录、个人信息和材料页面
- **THEN** 布局转为适合窗口的排列，不产生横向溢出，所有字段和按钮仍能在内容区域滚动到达
