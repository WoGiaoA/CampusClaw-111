# Spec Delta

## Purpose

允许班级工作台为登录账号保存可跨浏览器读取的显示昵称，并维持既有登录、会话、首次改密与班级权限。

## ADDED Requirements

### Requirement: 本人昵称持久化

系统 MUST 允许已完成首次改密的用户保存或清除本人昵称。

#### Scenario: 在不同浏览器读取
- **WHEN** 本人保存或清空昵称，随后在同一部署从另一会话打开页面
- **THEN** 个人信息与顶栏使用数据库中的最新昵称，未设置时顶栏只显示角色和班级

#### Scenario: 写入限制
- **WHEN** 缺少认证或有效 CSRF，仍需首次改密，或提交不合法字段
- **THEN** 拒绝写入并保留旧值

#### Scenario: 旧浏览器值
- **WHEN** 服务器从未保存昵称且浏览器有旧值
- **THEN** 编辑弹窗预填旧值，只有明确保存后才同步到账户
