# Design

## Context

本地部署有共享的 MySQL 账号库。现有昵称在各浏览器的 localStorage 内隔离。

## Goals / Non-Goals

**Goals:** 同一站点使用同一账号时，浏览器能读取最新昵称。

**Non-Goals:** 公网同步、账号改名或权限调整。

## Decisions

- 用户表增量添加可空昵称。NULL 表示从未保存，空字符串表示主动清空。迁移保护旧账号及资料。
- `GET /api/me` 返回昵称，`PATCH /api/me` 使用现有认证、CSRF 和首次改密门禁。严格接受本人昵称，去首尾空白，最多 24 个 Unicode 码点，拒绝控制字符。
- 旧昵称仅在服务端值为 NULL 时预填编辑弹窗，提交后删除本浏览器的旧值。这样另一个浏览器的旧值不会覆盖服务器已设置或已清除的值。

## Risks / Trade-offs

旧值只存在于原浏览器。需要在原浏览器打开弹窗并保存一次。服务器不可用时显示错误并保留草稿。
