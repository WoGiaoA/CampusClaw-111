# Proposal

## Why

CampusClaw 面向高校班级教学，需要先建立可信身份与班级数据边界，避免材料越权读取与上传。以教师上传、本班成员只读为首个闭环，为后续学期功能提供材料和知识库记录基础。

## What Changes

- 教师、学生使用账号密码登录，建立可信会话；未登录受保护页面跳转登录页，API 返回 401；错误密码不建立会话。
- 服务端角色授权：教师可上传本班材料，学生只读，调用上传接口返回 403。
- 服务端按可信会话的 class_id 过滤材料、知识库列表、详情和文件读取；跨班按 ID 访问统一 404，不泄露他班信息。
- 教师上传 UTF-8 txt/md，保存文件、解析文本，同事务创建材料与知识库记录；本班列表查库展示，失败回滚并清理文件。
- 规划班级、用户、讲义、作业、助手、技能六类结构及材料、知识库结构；预置 A/B 两班、两班教师与学生、可区分材料。未来功能只建结构。
- 密码使用单向哈希，密钥只通过服务端环境变量注入；规划 Docker Compose、持久化 volume 与免登录 GET /health。

## Capabilities

### New Capabilities

- `class-access`: 账号密码登录、会话、角色权限、可信班级边界和密码安全。
- `teaching-materials`: 本班材料与知识库读取、教师 txt/md 上传、解析记录与失败一致性。
- `project-runtime`: 核心结构、幂等测试种子、环境变量、Compose、健康检查与持久化。

### Modified Capabilities

无。当前 `openspec/specs/` 没有主规格。

## Impact

本次仅新增规约 Markdown 与简洁 README、AGENTS，不创建可运行应用。未来 Apply 将新增 Flask 应用、SQLite 初始化、登录/材料 API、最小登录与列表页面、依赖清单、Dockerfile、Compose 和环境变量示例；不涉及现有接口兼容性或旧库迁移。教师/学生、班级和材料数据受服务端鉴权约束。课表练习项目 `course-demo` 不受影响。

## Non-goals

- 不实现 AI 对话、向量检索、RAG 检索问答及模型调用；知识库入库仅材料保存、解析与记录。
- 不实现 AI 技能运行、开关、配置管理及 MCP 工具管理业务。
- 不实现作业提交、异步批改、教师最终评分、成绩管理、错题和学情分析。
- 不实现用户注册、找回密码、SSO 或第三方登录。
- 不实现生产高可用及复杂 CI/CD。
- 不复刻老师完整演示网站，不实现演示用预置账号选择首页。
- 不实现未来功能的完整业务页面，包括助手、关怀式对话、作业、审计和教学统计。
- 不增加材料编辑、覆盖或删除业务；未来结构预留不代表本次业务任务。
