# CampusClaw 全站视觉优化 · 第三课

本次为原生HTML/CSS/JS的视觉与展示交互优化。后端、数据库结构、API协议、CSRF、权限、账号及注册/改密规则均未修改；未引入框架、图片、图表或新业务。Docker构建/启停仍由用户负责，本次未执行。

## 页面与设计

- 配色统一为北大红#9B0000、中性浅灰背景、白色卡片和细边框。标题、正文、辅助信息分层，减少重复粗体和主色按钮。
- 保留50px品牌栏，导航与材料区共用最大1440px和24px桌面边距。平板/手机调整为16/12px边距；保留内容区域滚动，不隐藏溢出的操作。
- 登录：约1000px双栏、400px表单卡片、适度标题；减少英文装饰，次级注册说明。字段含中性默认、焦点、错误及autofill样式。
- 材料：约七三双栏，紧凑文件列表与数量；TXT/MD标识、标题/元信息、轻量查看和描边下载。长标题省略并保留完整title，操作不被挤压。短列表自然高度，长列表内部滚动；空状态简洁。
- 上传：标题、说明、字段、文件选择区和唯一红色主按钮统一排版；显示所选文件名与大小，保留原生file input、required、accept和FormData。
- 注册及个人信息复用相同表单、提示、按钮及导航风格。首登改密和普通改密逻辑不变。
- 操作：按钮hover/active/disabled/loading、输入focus/error、成功/错误/警告反馈统一；正文弹窗可用按钮或Escape关闭并清理DOM。
